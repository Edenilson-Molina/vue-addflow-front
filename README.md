# Frontend de la aplicación de flujo de caja

## Configuración del Proyecto
```shh
cp .env.example .env.local
```

```sh
npm install
```

### Compilar y recargar en tiempo real para desarrollo

```sh
npm run dev
```

### Compilar para producción

```sh
npm run build
```

### Lintear el código

```sh
npm run lint
```
